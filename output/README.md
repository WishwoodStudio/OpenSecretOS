# output/

## Purpose
Final, publish-ready or published episode output — the terminal artifact of
the production graph (Publishing → Published Episode).

## Ownership
Publishing Worker.

## What belongs here
Finished, cross-episode-indexed output ready for or already distributed.

## What must never be stored here
- In-progress work (belongs in the episode's own workspace under
  `episodes/` until it reaches Published state)
- Canonical documents
- Generated intermediates that aren't final deliverables

This folder is currently empty.
