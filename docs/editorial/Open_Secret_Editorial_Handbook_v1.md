# Open Secret Editorial Handbook v1

> **Status:** Editorial handbook (living document)\
> **Purpose:** Capture the editorial mindset and production philosophy
> that emerged through building and publishing Episode 1. This handbook
> complements, but does not replace, the canonical project documents.

# 1. Mission

Open Secret does not exist to teach business facts.

It exists to permanently improve how people explain the world around
them.

Every episode should leave the viewer with a better mental model, not
merely additional information.

------------------------------------------------------------------------

# 2. Success Metric

The primary question is **not**:

> "Was this interesting?"

The primary question is:

> "Did the viewer replace one mental model with a better one?"

Measure episodes by **Belief Distance**.

## Before

What does an intelligent viewer naturally believe?

## After

How should they explain the same system now?

The larger the genuine intellectual distance, the stronger the episode.

------------------------------------------------------------------------

# 3. Mechanisms over stories

Stories earn attention.

Mechanisms earn trust.

Facts are evidence.

Mechanisms are the product.

Every narrative decision should support revealing the underlying
mechanism.

------------------------------------------------------------------------

# 4. Topic selection

Before applying S9, apply a Belief Transformation filter.

Reject ideas that only add facts.

Prefer ideas that make viewers say:

> "I knew the fact. I never understood it that way."

Search for widely-held but incorrect beliefs first, then identify the
hidden mechanism that replaces them.

------------------------------------------------------------------------

# 5. Visual philosophy

Documentary Hybrid remains the foundation.

However, Episode 1 refined its execution.

Premium should come from authenticity, not stillness.

Prefer:

-   people
-   offices
-   logistics
-   factories
-   transport
-   visible business activity

Avoid depending on empty interiors and slow architectural shots.

Treat every \~15-second AI block as a short visual sequence, typically
2--3 connected shots.

Camera movement should reinforce existing activity rather than
substitute for it.

------------------------------------------------------------------------

# 6. Documentary evidence

Real documents are editorial assets, not supporting decoration.

Preferred workflow:

Claude → Evidence Request Package → Human retrieves sources → ChatGPT
produces polished evidence graphics → Claude integrates them.

------------------------------------------------------------------------

# 7. Mechanism diagrams

Diagrams explain the mechanism.

They should feel cinematic rather than presentation-like.

Workflow:

-   Claude defines the mechanism and writes the diagram brief.
-   ChatGPT produces the production-ready visual.
-   Claude integrates it into the edit.

------------------------------------------------------------------------

# 8. Automation philosophy

Automate repeated work.

Do not automate difficult work simply because it is technically
possible.

Production throughput is more valuable than theoretical elegance.

------------------------------------------------------------------------

# 9. Roles

Claude: - research - scripting - directing - assembly

ChatGPT: - strategic review - editorial challenge - premium visual
artifacts - mechanism diagrams - thumbnails - production critique

Human: - fast physical tasks - document retrieval - music selection -
publishing - final editorial judgment

------------------------------------------------------------------------

# 10. Decision hierarchy

1.  Production evidence
2.  Canonical project documents
3.  Editorial handbook
4.  New hypotheses

Never reverse this order.

------------------------------------------------------------------------

# 11. Knowledge evolution

Production Evidence → Postmortems → Editorial Handbook → Canonical
documents

Ideas become permanent only after repeated production validation.
