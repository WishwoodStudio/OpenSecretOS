# Open Secret OS --- Repository Philosophy

**Status:** Draft v0.1

The repository is not a file cabinet.

It is not documentation.

It is not backup.

It is the operating system itself.

Every directory exists because a production process requires it.

Every file has one owner.

Every artifact has one lifecycle.

Every canonical document has one authoritative location.

------------------------------------------------------------------------

# Golden Rule

If deleting a chat would lose important project knowledge, that
knowledge belongs inside the repository.

------------------------------------------------------------------------

# Three Valid Purposes

Every document must satisfy one of these:

1.  Define behavior.
2.  Execute production.
3.  Preserve knowledge.

Otherwise, it should not exist.

------------------------------------------------------------------------

# Repository Questions

The repository must always answer:

-   What is true?
-   What is happening?
-   What should happen next?

If a newcomer cannot answer these questions from repository contents
alone, the architecture is incomplete.

------------------------------------------------------------------------

# Architectural Direction

The repository will evolve into Open Secret OS.

Claude Code executes it.

Canonical documents govern it.

Workers perform specialized tasks.

Episode Workspaces become the primary production unit.
