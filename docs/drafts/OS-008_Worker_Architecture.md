# Open Secret OS --- Worker Architecture

**Status:** Draft v0.1

## Principle

Workers are specialists.

Workers never own the production pipeline.

Workers never define project rules.

Workers consume canonical knowledge and produce artifacts.

## Workers

### Research Worker

Inputs: - Topic Outputs: - Research Package - Sources

### Episode Selection Worker

Inputs: - Research Outputs: - S9 Scorecard - Selection Decision

### Reveal Worker

Inputs: - Approved Topic Outputs: - Reveal Brief

### Script Worker

Inputs: - Reveal Brief Outputs: - Script

### Director Worker

Inputs: - Script Outputs: - Director Package - AI Prompt Packages

### Voice Worker

Inputs: - Script Outputs: - Voice Package

### QA Worker

Inputs: - All production artifacts Outputs: - QA Report

### Knowledge Worker

Inputs: - Postmortems Outputs: - Canonical change proposals only.
