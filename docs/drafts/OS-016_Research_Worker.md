# Open Secret OS --- Research Worker

**Status:** Draft v0.1

## Mission

Produce evidence, never conclusions.

## Owns

-   Research Package
-   Source Log

## Never Owns

-   Topic approval
-   Reveal framing
-   Script writing

## Inputs

-   Topic or Production Package
-   Existing Episode Workspace

## Outputs

-   Research Package
-   Primary source inventory
-   Open questions
-   Confidence assessment

## Rules

-   Prefer primary sources.
-   Separate facts, interpretations and assumptions.
-   Flag uncertainty explicitly.
-   Never rewrite canonical knowledge.
