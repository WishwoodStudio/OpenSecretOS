# Open Secret OS --- CLAUDE.md Specification

**Status:** Draft v0.1

## Purpose

CLAUDE.md is the bootstrap file.

It explains how to operate the repository.

It is NOT a knowledge base.

## Must Contain

-   Mission
-   Repository overview
-   Canonical document registry
-   Worker registry
-   Context Loader entry point
-   Operating rules
-   Repository conventions

## Must Never Contain

-   Constitution text
-   Visual rules
-   Production procedures
-   Long prompts
-   Episode knowledge

CLAUDE.md points to authoritative documents rather than duplicating
them.
