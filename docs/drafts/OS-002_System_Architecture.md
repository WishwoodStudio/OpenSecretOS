# Open Secret OS --- System Architecture

**Status:** Draft v0.1

# Layers

    Human
        ↓
    Runtime
        ↓
    Knowledge
        ↓
    Workers
        ↓
    Integrations
        ↓
    Artifacts

## Human Layer

Owns strategy, editorial judgment, approvals and investment decisions.

Never automated.

## Runtime Layer

Claude Code orchestrates work.

It never becomes the source of truth.

## Knowledge Layer

Contains canonical project knowledge:

-   Constitution
-   Decision Log
-   Production Playbook
-   Visual Identity
-   Mechanism Ladder
-   Future canonical documents

## Worker Layer

Independent specialists:

-   Research Worker
-   Editorial Worker
-   Director Worker
-   Voice Worker
-   Publishing Worker
-   Knowledge Worker

Each owns one responsibility.

## Integration Layer

External capabilities:

-   Higgsfield
-   ElevenLabs
-   HyperFrames
-   Runway
-   Future APIs

Workers communicate through this layer.

## Artifact Layer

Everything produced by the system:

-   Episode Workspaces
-   Research
-   Scripts
-   Director Packages
-   Prompts
-   Assets
-   QA
-   Published Outputs

Artifacts are permanent and versioned.
