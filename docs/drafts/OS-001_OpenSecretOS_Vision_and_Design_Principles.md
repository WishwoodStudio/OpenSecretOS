# Open Secret OS --- Vision & Design Principles

**Status:** Draft v0.1

## Purpose

Open Secret OS exists to transform Open Secret from a collection of
prompts and documents into a production operating system.

The objective is **not** to replace human judgment.

The objective is to automate every deterministic production activity
while preserving human editorial control over strategic and creative
decisions.

Automation is a consequence---not the objective.

------------------------------------------------------------------------

# Core Principle

-   The repository is the operating system.
-   Claude Code is the runtime.
-   Canonical documents define behavior.
-   Skills execute specialized work.
-   External tools provide capabilities.
-   The human remains Editor-in-Chief.

------------------------------------------------------------------------

# Design Principles

## Repository First

The repository is the single source of truth.

Google Drive becomes archive.

Project Instructions become bootstrap only.

## Knowledge Before Execution

Claude should never improvise project rules.

Behavior should originate from canonical documents whenever possible.

## Load Only What Is Required

Context is assembled dynamically according to the production stage.

Loading the entire knowledge base by default is prohibited.

## Deterministic Before Intelligent

Represent repeatable behavior as rules.

Reserve reasoning for editorial work.

## One Responsibility

Every Skill owns one responsibility.

No Skill owns the complete production pipeline.

## Everything Becomes an Artifact

Research.

Reveal Brief.

Script.

Director Package.

Voice Package.

QA.

Publishing Package.

All are versioned artifacts.

Nothing important lives only in chat history.

## Production State Drives Execution

The repository state determines the next action.

## Replaceable Automation

Every external tool must be replaceable without redesigning the OS.

## Human Authority

Editorial and investment decisions always belong to the human.

------------------------------------------------------------------------

# Success Criteria

The OS succeeds when:

-   Claude can resume work after weeks with no chat history.
-   Every artifact has a permanent location.
-   Canonical knowledge grows without confusion.
-   Production effort decreases while editorial quality remains
    constant.
