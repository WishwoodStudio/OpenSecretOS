# Open Secret OS --- Production Contracts

**Status:** Draft v0.1

## Purpose

Production Contracts define the interfaces between Workers, Integrations
and Artifacts.

Workers never exchange free-form chat.

They exchange typed production artifacts.

------------------------------------------------------------------------

## Contract Principles

-   Every artifact has one owner.
-   Every artifact has one schema.
-   Every artifact has one lifecycle.
-   Every artifact declares upstream dependencies.
-   Every artifact declares downstream consumers.

------------------------------------------------------------------------

## Initial Contracts

-   Research Package
-   S9 Scorecard
-   Reveal Brief
-   Script Package
-   Director Package
-   Voice Package
-   QA Package
-   Publishing Package
-   Postmortem Package

Workers communicate only through these contracts.
