# Video Generation Prompt — Block E (Closing interior)

**Used in:** Beat 8 (0:43–0:58)
**Canonical citations:** `Visual Identity System v2` §2, §6.

- **Scene description:** quiet interior wide shot — could be the same
  boutique from a different, wider angle, or a neutral analogous space —
  must not visually contradict Block A.
- **Cinematic direction:** stillness that "lands" the takeaway.
- **Camera movement:** static hold, then a 2% push-in — within the
  canonical 2–5% push-in range (§6). Push-in start point: see below.
- **Mood:** resolved, calm.
- **Lighting:** consistent color temperature with Block A — this is the
  episode's visual bookend, matching the canonical "Two-register
  structure" recognizable signature (§7).
- **Composition:** wide, centered, generous lower-third space for
  closing typography.
- **Negative constraints:** no legible branding, no faces, no fast
  motion.

**Note on generation tool:** see Block A.

**Change from v2:** usage window changed from "Beats 8a–9" to "Beat 8" —
the locked script merged what were three separate beats (setup, payoff,
close) into one continuous beat, all still on this same block. The
push-in timing cue that used to be anchored to the start of beat 8b
("marks the payoff") no longer has a beat boundary to attach to. This
prompt keeps the same intent — push-in begins at the internal line "It's
not exclusivity built for you" — but that's this regeneration's
interpretation of where the merged beat's payoff moment falls, not
something the locked script states explicitly. Flagged in
`shot-list.md`, Production Issue #1, for review before shooting.
