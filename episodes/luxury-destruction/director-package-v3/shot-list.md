- **Camera language:** static frame, number centered; 2–3% push-in on

## Production issues discovered during this regeneration

1. **Beat 8's internal push-in cue has no beat boundary to attach to
   anymore.** v2 staged the 2% push-in as starting exactly at beat 8b
   ("marks the payoff"). The locked script merged 8a/8b/9 into one beat,
   so there is no longer a formal beat boundary at that point — only an
   internal sentence. This shot list preserves the original staging
   intent by naming the specific line ("It's not exclusivity built for
   you") as the push-in trigger, but this is this regeneration's own
   interpretation, not something stated in the locked script itself.
   Flagged for review before shooting: if Director Worker or a human
   director disagrees with where the push-in should land inside the
   merged beat, that's a legitimate open question this compression
   introduced.

2. **Timing figures are still planning estimates, not confirmed.** As
   with v1 and v2, every duration above is derived from word-count pace,
   not a real recording. No Voice Package exists yet for this episode.
   All beat boundaries — especially Beat 7's compressed 3-second
   duration, the shortest beat in the episode — need to be re-anchored
   against actual ElevenLabs word-level timestamps once VO is generated,
   per the same practice v1/v2 already established. A 3-second beat
   leaves very little slack if real delivery runs slower than the
   estimate.

3. **Everything already flagged in v2 and unrelated to the script
   change carries forward unresolved, unchanged:** Content Constitution
   v4 is still an empty placeholder in `canonical/` (affects Beat 8's
   compliance note, per above); the `prompts/higgsfield/` folder name
   still doesn't match Decision Log v2's named stack (Runway/Kling) —
   see `asset-manifest.md`. Neither is a consequence of this
   regeneration; both are restated here only so this shot list doesn't
   silently look like it resolved them.
