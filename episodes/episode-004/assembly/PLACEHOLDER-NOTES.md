## Intended motion graphic per placeholder

**Placeholder 1 (0:16–0:21) — "Receipts vs. real things."**
Narration draws a direct contrast: printable receipts vs. a house, vs.
food — things that can't be printed. A simple two-column or
before/after visual (matching this show's established comparison-diagram
language, e.g. the Luxury Destruction "Markdown Tax" diagram's build
pattern) showing a stack of receipts/bills on one side and a house/food
icon on the other, with the printable side able to multiply and the real
side staying fixed, would directly visualize the claim. Subtitle already
locked: "PRINT ≠ BUILD."

**Placeholder 2 (0:21–0:26) — "More receipts, same real things."**
Shortest, simplest beat — likely just an animated restatement of
placeholder 1's idea at smaller scale: many receipt icons multiplying
while the real-goods icon stays the same size/count. Could be a quick
reprise rather than a new diagram. Subtitle locked: "MORE MONEY / SAME
STUFF."

**Placeholder 3 (0:26–0:31) — "The pie gets cut into more slices."**
This is the episode's core mechanism statement — the closest analog to
Luxury Destruction's named-mechanism reveal beat. A literal pie-chart
style diagram (a fixed-size circle being divided into progressively more
slices as "money" is added) would directly illustrate the claim and sets
up beat 8's live-action pie/slice payoff that immediately follows.
Subtitle locked: "PIE → MORE SLICES." Recommend keeping this one
closest in spirit to Luxury Destruction's diagram treatment (same
Visual Identity System diagram build rules — opacity/translate build-in,
no more than the established color set), since it's this episode's
equivalent "named mechanism" moment, structurally.

   either stay as-is (it already matches the locked wording) or be
   redrawn inside the real motion graphic if the new graphic needs the
   text integrated into its own design — either is fine, the wording
   itself must not change.
3. Once real narration audio exists for this episode (see gap #1 in
   `production-log.md`), re-verify these three timestamps against the
   real recording before finalizing the graphics — the same
   re-anchoring step Luxury Destruction's narration required, since this
   episode's 37s estimate hasn't been validated against real speech
   either (see gap #2).
4. Diagram build style, if followed: reuse the existing color system
   (`Visual Identity System v2` §3) rather than introducing new colors —
   this episode has not used Amber/Red at all yet, so if the placeholder
   3 pie diagram needs a "cost" or "money" color distinction, those are
   available and unused so far, not already claimed by something else in
   this episode.
