# canonical/

## Purpose
Holds the documents that define how Open Secret behaves: the Constitution,
Decision Log, Production Playbook, Visual Identity, and Mechanism Ladder.
Only documents here may define rules.

## Ownership
Canonical documents are immutable except through the Knowledge Worker.
Promotion into this folder requires production evidence — ideas are never
promoted directly here.

## What belongs here
Ratified, authoritative documents only.

## What must never be stored here
- Drafts, proposals, or anything not yet ratified
- Episode-specific content
- Reference material (competitor research, templates, external inspiration)
- Anything a human hasn't approved through the proper gate

This folder is currently empty: no canonical documents have been ratified
yet.
