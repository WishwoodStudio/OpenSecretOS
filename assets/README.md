# assets/

## Purpose
Shared, cross-episode brand and production assets (fonts, logos, brand
elements, reusable graphics) — distinct from an episode's own assets, which
live inside that episode's workspace.

## Ownership
Governed by Visual Identity (a canonical document, once ratified).

## What belongs here
Assets meant to be reused across multiple episodes.

## What must never be stored here
- Episode-specific assets (belong in that episode's workspace under
  `episodes/`)
- Generated output (belongs in `output/`)
- Anything not sanctioned by Visual Identity once that document exists

This folder is currently empty.
